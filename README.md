# 🖼️ My Custom Image Gallery

A responsive, filterable image gallery built with **HTML, CSS, and JavaScript** as Task 1 of the [CodeAlpha](https://www.codealpha.tech/) Frontend Development Internship.

🔗 **Live Demo:** [khwaaishpatwa2110.github.io/codealpha-task-1](https://khwaaishpatwa2110.github.io/codealpha-task-1/)

---

## 📸 Preview

> A clean image gallery featuring category-based filtering and a full-screen lightbox viewer with navigation arrows.

---

## ✨ Features

- 🗂️ **Category Filtering** — Browse images by All, Animals, Cars, Space, Food, Travel, and Nature
- 🔍 **Lightbox Viewer** — Click any image to open it full-screen with a close button
- ◀️▶️ **Lightbox Navigation** — Previous / Next arrows to cycle through images without closing
- 📱 **Responsive Design** — Works seamlessly on desktop and mobile screens
- ⚡ **No dependencies** — Pure HTML, CSS, and JavaScript, zero libraries

---

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and image markup |
| CSS3 | Grid layout, filters, lightbox styling |
| JavaScript | Filter logic, lightbox open/close/navigation |
